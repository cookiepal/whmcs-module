# Security

Please report a security problem in this module privately, by email to
[support@cookiepal.io](mailto:support@cookiepal.io) with "Security" in the subject, rather than in a public issue.
Include the module version and the steps to reproduce it. We'll confirm we've received it and tell you what happens next.

If your agency API key may have leaked, ask CookiePal at the same address to revoke it and issue a new one. The old key
stops working within a minute.
